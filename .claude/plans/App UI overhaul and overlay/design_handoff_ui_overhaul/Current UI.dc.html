Context & assumptions
· Recreated from wellforce-brandon/DeafDirectionalHelper@main (WPF / .NET 8) — all values lifted from the XAML + code-behind, at default settings: mode Dual (vertical), profile ★ Default, indicators linked, so the 7.1-only settings panels are collapsed exactly as UpdateBarSettingsVisibility() hides them.
· Overlays are live: a simulated 200 ms audio poll with 1 s peak retention (matching Speakers.cs) drives the white → yellow → red gradient from ColorGradient.cs. Drop a real game screenshot onto any overlay demo.
· Title bars: the app never opts into dark Win32 chrome, so the real windows get the stock light title bar on a dark body — recreated as-is (a redesign fix candidate).
